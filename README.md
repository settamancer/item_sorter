# item_sorter

Раскладывает файлы из папки `files` по папкам номенклатурных единиц согласно `structure.csv`.

## Запуск

Нужен Python 3.8+ (сторонние библиотеки не нужны). Положите `item_sorter.py`, `structure.csv`
и папку `files` в одну папку и запустите `run.bat` (или `python item_sorter.py`).
Скрипт работает постоянно и каждые 5 секунд докопирует новые и изменённые файлы. Остановка — `Ctrl+C`.

Параметры:

- `--files ПАПКА` — исходные файлы (по умолчанию `./files`)
- `--csv ФАЙЛ` — файл связей (по умолчанию `./structure.csv`)
- `--dest ПАПКА` — куда раскладывать (по умолчанию `./Номенклатура`)
- `--interval СЕК` — пауза между проходами
- `--once` — один проход и выход

## Что делает

Для строки `02-0331;Сертификаты;Служебные материалы;Фото товара;Паспорт FO-R.pdf;...;FO-R.png`:

```
Номенклатура/02-0331/
    Паспорт 02-0331.pdf
    Сертификаты/Декларация ..._02-0331.pdf
    Служебные материалы/
    Фото товара/02-0331_3D.png
```

- Из имён убирается код модели перед артикулом (`FO-R_`, `FO-DM_`, `FO-D_`, `FO-RM_` и любые
  подобные: латинские буквы, цифры и дефисы). Файлы, разложенные раньше со старыми именами
  (`Паспорт FO-R_02-0331.pdf`), автоматически переименовываются.
- Все папки артикулов создаются в отдельной папке `Номенклатура`, а не рядом со скриптом.
- Исходники в `files` не удаляются (один файл нужен многим артикулам).
- Файл перекопируется, если в `files` появилась более новая версия.
- Файлы, указанные в CSV, но отсутствующие в `files`, выводятся в лог.

# photobank_sync

Копирует фотобанк с Synology (`\192.168.13.200\дм\ОПМ\БАЗА ПО ПРОДУКТАМ - ФОТОБАНК`) на локальный диск
и приводит папку каждой номенклатуры к единой структуре (как в `folder_example.zip`):

```
Фотобанк/<категория>/<артикул>/
    Паспорт <артикул>.pdf
    Описание/
    Сертификаты/
    Служебные материалы/
        Исходники/  Протокол испытаний/  Старые фото/  Упаковка/
    Фото товара/
```

## Запуск

`sync_photobank.bat` (или `python photobank_sync.py`). Параметры:

- `--src ПАПКА` — корень фотобанка на NAS (по умолчанию путь выше)
- `--dest ПАПКА` — куда копировать (по умолчанию `./Фотобанк`)
- `--only ТЕКСТ ...` — только категории/артикулы, в имени которых есть этот текст
- `--dry-run` — показать, что будет скопировано, ничего не меняя

## Как раскладываются файлы

- Копируются только 10 папок категорий (`1 LAN CCA кабель…` … `10 Телекоммуникационные шкафы…`) —
  папка берётся по номеру в начале имени (список `CATEGORIES` в скрипте). Остальные папки и файлы
  в корне фотобанка пропускаются; если какой-то категории нет, скрипт об этом предупредит.
- Каждая подпапка категории считается номенклатурой (имя может содержать буквы).
- Папки структуры создаются всегда (если файлов нет — остаются пустыми), кроме
  `Служебные материалы/Исходники` и `Служебные материалы/Старые фото`: они появляются, только если
  такая папка есть в источнике или в неё попадают файлы.
- Любая папка `Старые фото` переносится целиком в `Служебные материалы/Старые фото`: содержимое,
  подпапки и имена файлов не меняются.
- Изображения из корня номенклатуры с именами вида `05-0900_T1`…`_T6`, `_Y1`, `_Y2`, `_3D`
  (png/jpg/tif и т.п.) переносятся в `Фото товара`.
- Файлы, уже лежащие в папках с правильными именами (без учёта регистра), остаются на своём месте.
- Остальные раскладываются по правилам `RULES` в скрипте: `Паспорт*.pdf` — в корень, сертификаты (в т.ч. пожарные),
  декларации, отказные письма, уведомления об отказе, отрицательные решения, выписки из реестра
  российской продукции (ТОРП) — в `Сертификаты`, `*описани*` — в `Описание`, протоколы, этикетки/упаковка,
  RAW/PSD — в `Исходники`, фото `<артикул>_T1.png` — в `Фото товара`.
- Нераспознанные файлы из корня номенклатуры остаются в корне без изменений; нераспознанное из
  нестандартных папок попадает в `Служебные материалы` с сохранением исходных подпапок.
- Мусор Synology/Windows/macOS (`._DAV`, `@eaDir`, `#recycle`, `Thumbs.db`, `.DS_Store`) не копируется.
- Повторный запуск докопирует только новые/изменённые файлы. На NAS ничего не меняется.
